# DVR Bank — Bank Management System

A command-line banking portal built with Python, developed by **Divya, Rishika, and Srivaishnavi**.

---

## Features

- **User Authentication** — Secure sign-up and login with username/password validation
- **Account Management** — Supports Savings, Current, Joint, Salary, Business, and Student accounts
- **Money Transfers** — Instant account-to-account transfers within the bank
- **Loan Management** — Apply for and repay loans across six categories (Personal, Mortgage, Auto, Student, Business, Construction), with interest rates and repayment terms determined by your credit score
- **Credit Score Engine** — Automatically calculates credit scores based on annual income and payment history
- **Balance Inquiry** — View your current account balance at any time
- **Credit Card Offers** — Browse and apply for credit cards (Platinum Rewards, Gold Cash Back, Student Starter)
- **Notifications Center** — View your transaction history, loan history, and credit card application status
- **Customer Reviews** — Read and submit star-rated reviews, stored in a MySQL database
- **Account Deletion** — Close your account with confirmation

## Prerequisites

- Python 3.x
- MySQL Server
- `mysql-connector-python` library

Install the MySQL connector via pip:

```bash
pip install mysql-connector-python
```

---

## Database Setup

The customer reviews feature requires a MySQL database. Before running the application, create the database and table:

```sql
CREATE DATABASE MYFILE;
USE MYFILE;

CREATE TABLE reviews (
    username   VARCHAR(50),
    name       VARCHAR(100),
    rating     INT,
    review     TEXT,
    date       DATE
);
```

Then update the connection credentials in `sql.py` to match your local MySQL setup:

```python
obj = mysql.connector.connect(
    host="localhost",
    user="root",
    database="MYFILE",
    password="your_password"   # <-- update this
)
```

## How to Run

1. Clone or download the repository.
2. Ensure `file 1.csv` exists in the project directory (it can be empty; new users will populate it on sign-up).
3. Start the application from the project root:

```bash
python main.py
```

4. Follow the on-screen prompts to sign up or log in.

---

## Notes

- A minimum deposit of **₹2,000** is required to open an account.
- Loan eligibility and interest rates (3–7%) are determined automatically by the built-in credit score engine.
- Transaction history is saved to a plain-text file named after each user (e.g., `BLUE.txt`).
- The `__pycache__` directory is auto-generated by Python and can be ignored or added to `.gitignore`.
